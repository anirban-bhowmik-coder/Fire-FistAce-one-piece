## 🌋 About

**Fire Fist** is a cinematic, interactive web experience inspired by the world and legacy of **One Piece**, with a particular focus on the character and symbolism of **Portgas D. Ace**.

The project combines:

- 🔥 Fire-inspired visual effects
- 🎬 Cinematic storytelling
- ⚡ Interactive cursor effects
- 🌌 Futuristic visual design
- 📖 Chapter-based storytelling
- 🖥️ Responsive web experience
- ✨ Motion and atmospheric effects

The goal was not to build another conventional fan page.

Instead, Fire Fist was created as an **immersive digital experience** where visual design, animation, typography, and storytelling work together.

## ✨ Experience

### 🔥 Cinematic Hero

A visually focused opening section designed to immediately establish the atmosphere of Fire Fist.

### ⚡ Interactive Lightning Cursor

The experience includes a custom cursor system featuring:

- Lightning effects
- Sparks
- Dynamic movement
- Interactive visual feedback

### 📖 Storytelling

The website presents its narrative through structured chapters rather than a traditional static webpage.

### 🌋 Atmospheric Visual Design

The interface uses:

- Dark cinematic backgrounds
- Fire-inspired imagery
- Glowing effects
- Radial lighting
- Motion
- Layered visual elements

### 📱 Responsive Interface

The website is designed to provide an immersive experience across different screen sizes.
