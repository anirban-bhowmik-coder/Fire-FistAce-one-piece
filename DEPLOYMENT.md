# Fire Fist — Independent Website Deployment

This version preserves the existing Fire Fist website design and interactions while replacing Manus-hosted artwork/runtime dependencies with local assets.

## Local assets
- `client/public/images/ace-fire-fist.png` — primary Ace Fire Fist artwork
- `client/public/images/ace-futuristic-wallpaper.png` — futuristic wallpaper layer

## Local development
```bash
pnpm install
pnpm dev
```

## Production build
```bash
pnpm build
```

## Vercel
Deploy the repository with the included `vercel.json`.
